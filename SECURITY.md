# Security reporting

Please report suspected vulnerabilities privately using [Report a vulnerability](https://github.com/adrienwax/moshpit/security/advisories/new).
Do not put exploit details, credentials or private media in a public issue.

Include the affected commit/version, operating system, reproduction steps and
potential impact. Use a minimal synthetic example where possible. Do not attach
personal projects or unredacted logs. Ordinary bugs belong in [Issues](https://github.com/adrienwax/moshpit/issues).

This project is maintained on a best-effort basis. There is no guaranteed response
time or long-term support policy; fixes target the current source branch. Please
allow time to investigate and coordinate disclosure before publishing details.

If the private reporting form is unavailable, do not post sensitive details
publicly. Open an issue asking for a private reporting channel without describing
the vulnerability.
