# Moshpit quick start

1. Put three short video clips you own in one folder.
2. Home > Starter Mosh: choose the folder and wait for preparation.
3. In MOSH, play the sequence. Select the middle MOTION block and its Melt effect.
4. Turn Bypass off to enable it. Change one parameter and compare. Ctrl+Z undoes an edit.
5. Ctrl+S saves an editable .mosh project. Keep the source clips available.
6. OUT > H.264: use Browse beside Output folder, then Render > Add job. Wait for the queue to finish.

A project is not an exported video. Saving it does not collect the source media.
Hover controls for INFO; reopen errors through Notifications at the bottom right.
